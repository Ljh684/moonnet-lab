# 路线图

按"每个里程碑结束时仓库里都有一件能运行、能验证的东西"来切分。状态以 `main` 分支的实际代码为准。

## M1 · 确定性内核与网络层（完成）

交付：

- 虚拟时间（皮秒整数）、事件队列、事件日志
- 冻结的随机源，带参考向量的回归测试
- 数据包模型、有界队列（drop-tail、按包数与按字节双限制）、链路（带宽、传播延迟、抖动、利用率）
- CLI 骨架：`moonnet version` / `moonnet demo` / `moonnet help`
- 25 个测试，覆盖时间换算、事件排序、堆行为、队列丢弃、链路串行化与抖动的可复现性

验收方式：`moon test` 全绿；同一场景两次运行的到达时刻序列完全一致。

## M2 · TCP 协议栈（进行中）

交付：

- 发送端与接收端状态机（CLOSED / SYN-SENT / ESTABLISHED / FIN-WAIT 等）
- 序号空间、累计确认、延迟 ACK、接收窗口与流量控制
- 滑动窗口、重传队列、RTO 超时重传（Karn 算法、指数退避）
- 快速重传与快速恢复
- 场景：单个长连接在无丢包链路上跑满带宽，到达时间与解析计算一致

验收方式：无丢包场景的吞吐等于解析值；注入丢包后重传次数与窗口演化符合预期。

## M3 · 拥塞控制与队列管理（计划中）

交付：

- 可插拔的拥塞控制接口（trait），算法作为独立模块实现
- Reno（RFC 5681）、CUBIC（RFC 9438）、Vegas
- AQM：RED、CoDel，与 drop-tail 在同一接口下互换

验收方式：每个算法都有单元测试覆盖其窗口增长与回退规则；同一场景下三种算法的对比结果稳定复现。

## M4 · 实验与报告（计划中）

交付：

- 场景文件的读写（拓扑、流量、参数、种子）
- `moonnet run`（单场景）、`moonnet compare`（多算法对比）、`moonnet sweep`（参数扫描）
- 指标导出 JSON：吞吐、RTT、cwnd 轨迹、队列占用、重传率、Jain 公平性指数、链路利用率
- 自渲染 SVG 图表，不依赖第三方绘图库

验收方式：同一场景重复运行导出的 JSON 逐字节一致；图表由 CI 产物生成。

## M5 · 文档与案例（计划中）

交付：

- 三个完整案例：丢包下的算法对比、缓冲区深度与排队延迟、多条流的公平性
- 开发历程文章：设计取舍、被推翻的方案、AI 工具在其中的作用与边界

## 明确不做

- 通用离散事件仿真框架（生态已有 moonsim / moondes）
- pcap 抓包解析（已有成熟实现）
- 与真实网络协议栈互操作（本项目的目标是把行为讲清楚，不是替代内核）
